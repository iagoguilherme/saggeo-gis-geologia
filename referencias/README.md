# Referências

Documentação, cursos, livros e comunidades. Só entra o que foi lido ou
usado; cada item diz para que serve.

## Documentação oficial

| Referência | Para quê | Link |
|---|---|---|
| **QGIS User Guide** (pt-BR parcial) | manual completo; consultar antes de procurar plugin, muita coisa já é nativa | https://docs.qgis.org/latest/pt_BR/docs/user_manual/ |
| **QGIS Training Manual** | curso oficial passo a passo, bom para onboarding | https://docs.qgis.org/latest/en/docs/training_manual/ |
| **PyQGIS Developer Cookbook** | automação dentro do QGIS (console, plugins, Processing) | https://docs.qgis.org/latest/en/docs/pyqgis_developer_cookbook/ |
| **Repositório oficial de plugins** | buscar, ver versão, downloads, changelog, experimental ou não | https://plugins.qgis.org/ |
| **GDAL** | referência dos utilitários (`gdalwarp`, `gdal_translate`, `ogr2ogr`) | https://gdal.org/ |
| **GRASS GIS manual** | módulos `r.*` e `v.*` usados pelo Processing | https://grass.osgeo.org/grass-stable/manuals/ |
| **EPSG.io** | conferir códigos de SRC (4674, 31982, 31983, 4326) | https://epsg.io/ |

## Livros e apostilas

| Título | Para quê |
|---|---|
| *QGIS Map Design* (Anita Graser, Gretchen Peterson) | cartografia e layout de impressão bem feitos |
| *Geoprocessing with Python* (Chris Garrard) | GDAL/OGR em Python do zero |
| *Hidrogeologia: conceitos e aplicações* (Feitosa et al., SGB/CPRM) | referência brasileira de hidrogeologia; capítulos de locação e mapas |
| *Structural Geology Algorithms* (Allmendinger, Cardozo, Fisher) | base matemática de estereogramas e projeções |
