# Autores e curadores

Quem publica ou desenvolve ferramentas GIS úteis para geologia e vale
acompanhar. Cada perfil tem uma avaliação: o que a pessoa produz, o que
entrou no catálogo (com ficha), o que ficou de fora e por quê, e como
acompanhar novidades.

## Como avaliar um autor

1. Levantar todas as fontes: perfil na loja do QGIS, GitHub/GitLab, site,
   LinkedIn (aba Atividades), YouTube.
2. Listar cada ferramenta com: gratuita ou paga, onde está, versão e data,
   licença, compatibilidade QGIS.
3. Aplicar o critério de entrada de [../README.md](../README.md):
   gratuita, resolve algo concreto de geologia, verificável.
4. O que entra ganha ficha normal na categoria certa; o que não entra fica
   registrado no perfil do autor com o motivo (fora de escopo, paga,
   duplicada, sem licença).
5. Registrar o que **não** foi possível verificar.
