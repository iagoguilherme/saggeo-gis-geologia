## Critério de entrada

Uma ferramenta entra no índice quando:

1. é gratuita ou tem versão gratuita utilizável (pagas entram só como
   "alternativa" nas fichas, com a observação de custo);
2. resolve algo concreto de geologia/hidrogeologia que o QGIS puro não
   resolve ou resolve mal;
3. foi verificada: página oficial, código, licença, última atualização.

## Legenda de status

| Status | Significado |
|---|---|
| `ativo` | release ou commit nos últimos 12 meses e compatível com o QGIS LTR atual |
| `manutenção esporádica` | funciona, mas atualizações raras; testar antes de depender |
| `abandonado` | sem atualização há mais de 3 anos ou marcado como deprecated; usar só se não houver alternativa |
| `experimental` | marcado como experimental na plugins.qgis.org; precisa habilitar "mostrar plugins experimentais" |
